# FashionMind AI image assets

The homepage currently uses fashion photography hosted by Unsplash through `images.unsplash.com` URLs in `index.html`. The images are decorative sample imagery and are not user uploads or AI-generated recommendations.

To use local assets later, add appropriately licensed images to this directory and update the corresponding image `src` values in `index.html`. The image containers keep their background colors if an external image cannot be loaded.
